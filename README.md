# Termux - Git Skills CLI Game

### 🎮 Test your Git skills through this interactive CLI game

Take your Git skills to the next level with **Termux** - an engaging command-line game that teaches Git through hands-on challenges!

## ✨ Features

### 🎯 **Interactive Challenges**
- **20+ Git challenges** across 3 difficulty levels
- **Real-time feedback** with hints and explanations
- **Progressive learning** from basic to advanced Git commands
- **Second-chance system** for learning from mistakes

### 🏆 **Gamification Elements**
- **Scoring system** with points for correct answers
- **Leaderboard** showing top players
- **Achievement system** with 8 unlockable badges
- **Daily challenges** for consistent practice
- **Progress tracking** across all difficulty levels

### 👤 **User Management**
- **User registration and login**
- **Guest mode** for quick play
- **Progress persistence** across sessions
- **Personal statistics** and achievements

### 📚 **Educational Content**
- **Comprehensive help system** with common Git commands
- **Detailed explanations** for each challenge
- **Progressive difficulty** from beginner to advanced
- **Real-world Git scenarios**

## 🚀 Getting Started

### Installation
```bash
npm install
```

### Running the Game
```bash
# Development mode
npm run dev

# Production mode
npm run build
npm start
```

## 🎮 How to Play

1. **Start the game**: Run `npm run dev`
2. **Choose your mode**: Register, login, or play as guest
3. **Select challenges**: Pick from beginner, intermediate, or advanced
4. **Solve puzzles**: Enter the correct Git command
5. **Track progress**: View your stats and achievements
6. **Compete**: Check the leaderboard and daily challenges

## 🏅 Achievement System

- **First Steps** 🌱 - Complete your first challenge
- **Beginner Master** 🌱 - Complete all beginner challenges
- **Intermediate Master** ⚡ - Complete all intermediate challenges
- **Advanced Master** 🚀 - Complete all advanced challenges
- **Perfect Score** 💯 - Get 100 points in a single session
- **Speed Runner** ⚡ - Complete 3 challenges quickly
- **Persistent Learner** 📅 - Play for 7 consecutive days
- **Git Guru** 👑 - Complete all challenges
